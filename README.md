# Klötzli

Fallklötzchen-Spiel fürs Handy als installierbare Web-App, in zwei Designs:

- **Retro**: grüner Pixel-Bildschirm im Stil eines Handhelds von 1989, klassische Regeln, A-Type und B-Type.
- **Modern**: glänzende Steine, hell oder dunkel, mit Schattenstein, Halten, Sofort-Ablegen, Wischgesten, Marathon und Sprint 40.

Das Design wird in den Einstellungen umgestellt: Retro mit dem Knopf «Einstellungen» unter dem Bildschirm oder im Startbildschirm in der Zeile DESIGN; Modern mit dem Zahnrad oben rechts oder im Menü.

**Spielen:** https://rschieler.github.io/Kloetzli/
Installieren: Link in Chrome öffnen → Menü ⋮ → «App installieren».

Die Musik ist das russische Volkslied «Korobeiniki» (19. Jahrhundert).
